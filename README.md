# HTML Practice Project

This project was created as part of an HTML learning assignment.

## Project Contents

### 1. Personal Website (index.html)
The page includes:

- Headings
- Paragraphs
- Bold and italic text
- Centered content
- Images
- Links
- Lists
- Tables
- YouTube video
- Audio player

### 2. Register Form (register.html)

The registration form contains:

- Name
- Surname
- Email
- Password
- Gender
- Age
- Country
- Address

The form sends data to:

https://httpbin.org/post

using the POST method.

### 3. CV / Resume (cv.html)

The CV page includes:

- Personal information
- Profile picture
- About Me section
- Education
- Skills
- Projects
- Social Media links
- Contact information
